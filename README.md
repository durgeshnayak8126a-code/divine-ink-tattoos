# Divine Ink Tattoos & Piercing Studio Website V2

A fresh React + Vite website built from the supplied original assets.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production-ready output will be generated in the `dist` folder.
